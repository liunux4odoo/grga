## 🎯 快速上手（Code Agent 阅读顺序）

1. **先读 `v2-design.md` §0-§3**（TL;DR + 产品定位 + 用户哲学 + 三个决策）—— 建立整体认知
2. **再读 `v2-design.md` §4**（三层扩展模型 L1/L2/L3）—— 核心能力设计
3. **再读 `v2-design.md` §5-§7**（架构分层 + 数据模型 + API 契约）—— 实现约束
4. **然后读 `v2-plan.md` §全局原则 + §依赖关系总览** —— 铁律不能违反
5. **最后读 `v2-plan.md` Phase 0-6** —— 具体 task 分解

## ⚡ 三条铁律（摘自 v2-plan.md）

1. **Layer 1 是旁路增强层，不阻塞 Layer 0** —— ripgrep-all 主链路保持原样
2. **保护 v1 自用能力** —— 新代码走独立模块，`search.py` / `deep_search.py` 只允许"非侵入式扩展"（新增字段、新增可选参数），不重构
3. **每个 Agent API 动词幂等 + 可预测** —— `search / expand / related / suggest` 独立、无隐藏状态、无内部反思循环

## 🚀 从哪儿开始动手
